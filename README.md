# Self Employed Checker

## Описание
Библиотека для проверки статуса самозанятого через API ФНС (Федеральная налоговая служба России).

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd <repository-directory>
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование

```python
from __init__ import SelfEmployedChecker

# Проверка статуса самозанятого
inn = "123456789012"  # ИНН физического лица
request_date = "2023-10-01"  # Дата запроса в формате ГГГГ-ММ-ДД

result = SelfEmployedChecker.check_status(inn, request_date)

if result:
    print("Статус самозанятого подтверждён")
else:
    print("Статус самозанятого не подтверждён или произошла ошибка")
```

## Параметры метода `check_status`

| Параметр | Тип | Описание |
|----------|-----|----------|
| `inn` | str | ИНН физического лица (10 или 12 цифр) |
| `request_date` | str | Дата запроса в формате ГГГГ-ММ-ДД |

## Возвращаемое значение

Метод возвращает `bool`:
- `True` — статус самозанятого подтверждён
- `False` — статус не подтверждён, неверные данные или ошибка сервиса

## Обработка ошибок

Метод может вернуть `False` в следующих случаях:
- Неверный формат даты
- Дата находится в будущем
- Ошибка валидации данных
- Сервис ФНС временно недоступен
- Превышено количество запросов к API
- Ошибка соединения
